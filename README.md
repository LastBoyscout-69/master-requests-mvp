# MVP: Заявки на выезд мастера (веб + Telegram)

Простой сервис для приёма заявок от клиентов через веб‑форму и Telegram‑бота. Все заявки хранятся в единой SQLite‑базе, статусы можно менять в веб‑интерфейсе.

## Зачем это нужно

Решение для небольшой сервисной компании: заявки приходят и через сайт, и через привычный для клиента Telegram, диспетчер видит все заявки в одном месте и меняет статусы.

## Стек

- Python 3.11+
- FastAPI (веб‑сервис + API)
- aiogram 3.x (Telegram‑бот)
- aiosqlite (асинхронная работа с SQLite)
- Jinja2 (шаблоны HTML)
- uvicorn (ASGI‑сервер)
