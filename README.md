# Заявки на выезд мастера (MVP)

Простой веб‑сервис на FastAPI для приёма и отслеживания заявок.

## Что умеет

- Подача заявки: имя, телефон, описание проблемы.
- Список всех заявок в виде таблицы.
- Смена статуса заявки: «В работе» / «Готово» прямо из списка.
- Автоматическая инициализация базы данных при первом запуске.

## Стек технологий

- Python + FastAPI
- Асинхронная работа с SQLite через aiosqlite
- HTML‑формы (без тяжёлых фронтенд‑фреймворков)
- База данных создаётся автоматически при старте

## Как запустить

1. Создай виртуальное окружение:  
   `python -m venv venv`
2. Активируй его (Windows):  
   `venv\Scripts\activate`
3. Установи зависимости:  
   `pip install -r requirements.txt`
4. Запусти сервер:  
   `uvicorn web_service:app --host 0.0.0.0 --port 8000`

После первого запуска в папке проекта автоматически появится файл базы данных `requests.db`.

## Куда развивать дальше
Этот MVP можно докрутить под реальные задачи (например, под интеграцию с WMS или диспетчерской системой):

- Добавить авторизацию для диспетчера (чтобы менять статусы мог только свой человек).
- Сделать выгрузку списка в CSV/Excel.
- Обернуть в Docker для простого деплоя.
- Добавить тесты (pytest) для проверки создания заявки и смены статуса.
